# BCH Address Tool

Validate and convert any Bitcoin Cash address — detects format, network, CashTokens support, and converts between CashAddr and token-aware CashAddr.

**Live demo:** https://bch-address-tool.netlify.app  
**Starter branch:** https://github.com/vybzcody/bch-address-tool/tree/starter

## Stack

Vite + React + TypeScript — no dependencies beyond React itself.

## Get started

```bash
git clone https://github.com/vybzcody/bch-address-tool
cd bch-address-tool
npm install
npm run dev
```

To follow the build-from-scratch tutorial, use the `starter` branch:

```bash
git clone -b starter https://github.com/vybzcody/bch-address-tool
```
